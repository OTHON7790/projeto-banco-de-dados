# Projeto de Banco de Dados — Sistema Escolar

## Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais de Banco de Dados e SQL, utilizando um cenário simples de sistema escolar.

O banco foi estruturado para armazenar informações de alunos, cursos e matrículas.

## Estrutura do banco de dados

O banco de dados utilizado no projeto chama-se:

`escola`

Foram criadas três tabelas principais:

- `alunos`
- `cursos`
- `matriculas`

A tabela `matriculas` realiza o relacionamento entre alunos e cursos.

## Arquivos do projeto

### 01_criacao_banco.sql

Responsável pela criação:

- do banco de dados `escola`;
- da tabela `alunos`;
- da tabela `cursos`;
- da tabela `matriculas`;
- das chaves primárias;
- das chaves estrangeiras.

### 02_insercao_dados.sql

Responsável pela inserção de dados de exemplo nas tabelas:

- alunos;
- cursos;
- matrículas.

### 03_consultas.sql

Contém exemplos de consultas SQL utilizando:

- SELECT;
- WHERE;
- INNER JOIN;
- relacionamento entre tabelas.

## Conceitos praticados

Neste projeto foram praticados conceitos como:

- criação de banco de dados;

- chave estrangeira;
